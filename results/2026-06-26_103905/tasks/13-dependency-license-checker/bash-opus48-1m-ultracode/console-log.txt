### The script (`license-checker.sh`)
Parses `package.json` *or* `requirements.txt` (format auto-detected by content), looks up each dependency's license via a **mockable seam** (`--license-db` file — the single impure function), classifies against an allow/deny policy (`config/license-policy.conf`), and emits a text or JSON report. Statuses: **approved / denied / unknown**, with deny taking precedence and case-insensitive matching. Graceful errors with distinct exit codes (0 ok, 1 denied-with-`--fail-on-denied`, 2 usage, 3 input).

### TDD progression (6 red→green cycles)
CLI contract → package.json parsing → requirements.txt parsing → policy + mock lookup + classification → end-to-end text report + exit codes → JSON output.

### The pipeline (`.github/workflows/dependency-license-checker.yml`)
- Triggers: `push`, `pull_request`, `schedule` (weekly cron), `workflow_dispatch` (with a `fail_on_denied` input)
- `permissions: contents: read`, env vars, and a job dependency: **`license-check` needs `lint-and-test`**
- Stage 1 installs bats+shellcheck, runs `bash -n`, `shellcheck`, and the bats unit suite; Stage 2 resolves the manifest, generates the report, publishes it to the job summary, and runs a (report-only by default) policy gate — all inside the `actions/checkout@v4` Docker container, no external services/secrets

### The act harness (`tests/workflow.bats`)
Per case (`approved`, `denied`, `requirements`): assembles a throwaway git repo with the project files + that case's fixture, runs `act push --rm`, appends delimited output to `act-result.txt`, and asserts **exact** values — e.g. `Summary: 4 dependencies, 2 approved, 1 denied, 1 unknown`, `gpl-python-lib … GPL-3.0 … DENIED` — plus act exit 0 and `Job succeeded` for every job. A PyYAML validator (`tests/check_workflow.py`) checks triggers/jobs/steps/paths, and actionlint is asserted at exit 0.

I de-risked thoroughly before spending act runs (ran the workflow's exact commands via `docker run`, validated structure with `bats --filter 'structure:'`), so the single harness execution passed all three cases first time.
