### TDD methodology
Each capability was added red-first (saw the failing test) then green: `parseManifest` → `detectManifestType`/`checkLicense` → `generateReport`/`lookupFromDatabase`/`renderReport` → `runCli`. Covers package.json **and** requirements.txt, deny-over-allow precedence, case-insensitivity, dedup, malformed-input errors, and exit codes (0 ok / 1 strict-violation / 2 usage-IO).

### The "mock the license lookup" requirement
The lookup is an injectable `LicenseLookup` function — tests pass a `mock()`, and CI passes a JSON-backed `lookupFromDatabase(...)`, keeping the whole pipeline deterministic and offline.

### Workflow
Triggers `push`/`pull_request`/`schedule`/`workflow_dispatch`; `permissions: contents: read`; env-configured config/license paths; two jobs with a dependency edge (`license-compliance` `needs: unit-tests`); pinned valid action refs (`actions/checkout@v4`, `oven-sh/setup-bun@v2`). Report-only gate that annotates (doesn't fail) on non-compliance, so every job stays green. **actionlint: exit 0.**
