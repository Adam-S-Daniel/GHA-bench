## Summary

### What it does
`version_bumper.py` reads a version from a `VERSION` file or `package.json`, classifies conventional commits (`feat!:`/`BREAKING CHANGE:` → major, `feat:` → minor, `fix:` → patch, else no release — highest precedence wins), bumps the version, writes it back (preserving other JSON keys), prepends a grouped markdown changelog, and prints the new version. Errors raise `SemverError` with meaningful messages and exit non-zero.
