## What was built

A **semantic version bumper** in Node.js (zero dependencies — uses built-in `node:test`, `node:fs`), developed with strict red/green TDD.

### TDD progression (each function: failing test → minimum code → green)
1. `parseCommits` — parses conventional commits (`type(scope)!: desc`, `BREAKING CHANGE:` footer), splits on a `--==COMMIT==--` delimiter, skips junk
2. `determineBump` — breaking→major, feat→minor, fix→patch (highest precedence wins), else null
3. `bumpVersion` — applies the bump, tolerates leading `v`, rejects malformed versions/types with clear errors
4. `readVersion`/`writeVersion` — handles both plain `VERSION` files and `package.json` (preserving keys)
5. `generateChangelog` — grouped, dated Markdown sections, omits empty ones
6. `bump` — end-to-end orchestration (read → decide → write → prepend changelog)
