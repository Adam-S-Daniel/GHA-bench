## Summary

Built a PowerShell artifact-cleanup tool test-first with Pester, plus a GitHub Actions pipeline validated end-to-end through `act`.

### The engine (`ArtifactCleanup.psm1`)
A pure policy engine that takes artifacts (`Name`, `Size`, `CreatedAt`, `WorkflowRunId`) and applies three optional retention policies in order:
1. **MaxAgeDays** — delete anything older than N days
2. **KeepLatestPerWorkflow** — per `WorkflowRunId`, keep the N newest, delete the rest
3. **MaxTotalSize** — of the survivors, delete oldest-first until total fits the cap

Reasons accumulate per artifact, and it emits a plan (per-artifact decisions + summary: total/retained/deleted counts, space reclaimed). `Invoke-ArtifactCleanup` adds dry-run support and a pluggable delete action; input is validated with meaningful errors.

### TDD methodology
Genuine red/green/refactor — started with an empty module and a failing test (confirmed RED), implemented to green, then hit a real `Set-StrictMode` bug (`Measure-Object` over an empty pipeline) which I refactored out with a safe-sum helper. **23 unit tests pass.**
