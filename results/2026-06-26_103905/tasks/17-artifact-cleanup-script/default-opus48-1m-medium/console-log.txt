## Solution overview

A PowerShell + Pester artifact-retention tool, built with strict **red/green TDD** (each function had a failing test written first, then minimal code, verified at every step).

### Core logic — `ArtifactCleanup.psm1`
Five functions, each test-driven:
- `New-Artifact` — fixture factory that normalizes `createdAt` to UTC `[datetime]`
- `Get-ArtifactDeletionPlan` — applies the three policies in deterministic order:
  1. **max age** → delete artifacts older than N days
  2. **keep-latest-N per workflow** → group by workflow, keep the N newest
  3. **max total size** → delete oldest survivors until under the cap
  
  Earlier-policy deletions aren't re-evaluated; each deletion carries a human-readable `Reason`.
- `Get-ArtifactSummary` — counts + space reclaimed/retained
- `ConvertTo-Artifact` — JSON loading with meaningful errors on missing fields
- `Invoke-ArtifactCleanup` — orchestration with **dry-run** mode (injectable `-OnDelete` callback, invoked only when *not* dry-run)

### Tests
- `ArtifactCleanup.Tests.ps1` — **17 unit tests**, all passing (run inside CI via act)
- `Workflow.Tests.ps1` — **11 structure tests** (triggers, jobs, `needs` dependency, permissions, file references, actionlint exit 0)

### CI/CD — `.github/workflows/artifact-cleanup-script.yml`
