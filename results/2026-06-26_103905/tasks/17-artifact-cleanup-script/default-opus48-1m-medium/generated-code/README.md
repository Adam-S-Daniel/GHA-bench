# Artifact Cleanup Script

Applies retention policies to a list of build artifacts and produces a **deletion
plan** with a summary. Nothing is ever actually deleted — the plan is the
deliverable, which keeps the logic pure and trivially testable, and makes
`--dry-run` a first-class mode.

## Files

| File | Purpose |
|------|---------|
| `artifact_cleanup.py` | Core logic + CLI |
| `test_artifact_cleanup.py` | Unit tests (pure logic, written red→green) |
| `test_workflow.py` | Workflow structure tests + `act` end-to-end harness |
| `fixtures/artifacts.json` | Sample artifact metadata |
| `fixtures/policy.json` | Sample retention policy |
| `.github/workflows/artifact-cleanup-script.yml` | CI/CD pipeline |
| `act-result.txt` | Captured output of the `act` runs (generated by tests) |

## Retention policies (all optional)

1. **`keep_latest_per_workflow`** (protective + active) — within each workflow
   group the N most-recent artifacts are always kept; the surplus is deleted.
2. **`max_age_days`** — delete unprotected artifacts older than N days.
3. **`max_total_size_bytes`** — if the retained set still exceeds the budget,
   delete the oldest unprotected survivors until it fits.

**Precedence:** keep-latest wins over everything, then max-age, then max-total-size
acts as a final squeeze.

## Usage

```bash
python3 artifact_cleanup.py \
  --artifacts fixtures/artifacts.json \
  --config fixtures/policy.json \
  --dry-run \
  --now 2026-06-26T12:00:00Z \
  --output plan.json
```

`--now` makes age calculations deterministic (defaults to current UTC). `--output`
writes the full plan JSON; the human-readable summary always prints to stdout.

## Testing

```bash
pytest            # everything (unit + workflow structure + act end-to-end)
pytest -k "not through_act"   # fast: skip the Docker/act runs
```

All artifact testing flows through the GitHub Actions workflow via `act` (nektos/act),
which exercises the script exactly as CI would.
