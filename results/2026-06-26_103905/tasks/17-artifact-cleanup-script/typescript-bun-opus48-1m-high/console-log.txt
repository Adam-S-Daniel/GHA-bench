## Solution

A TypeScript/Bun artifact-cleanup tool built with strict red/green TDD — each piece had a failing test written first, then minimum code to pass.

**Core modules** (separated so the logic stays pure and testable):
- `src/cleanup.ts` — pure planner: `planCleanup(artifacts, policy, {now})` → `DeletionPlan`. Implements the three retention rules:
  - **max age** and **keep-latest-N-per-workflow** each mark artifacts for deletion independently (union)
  - **max-total-size** applied last, evicting oldest survivors until the retained total fits the budget
  - documented, deterministic combination semantics
- `src/parse.ts` — validates untrusted JSON with precise errors (`artifacts[1].sizeBytes must be a non-negative number`)
- `src/render.ts` — stable, parseable text report
- `src/cli.ts` — thin I/O layer; `--dry-run`/`DRY_RUN` mode, exit codes 0/1/2

**Tests** — 34 passing across 5 files (`bun test`): each retention rule, combinations, edge cases (empty list/policy), input validation, CLI orchestration, and workflow structure + actionlint.
