## Summary

Built an artifact retention/cleanup tool in **Bash** using red/green TDD, with a real GitHub Actions pipeline validated end-to-end through `act`.

### Deliverables
- **`artifact-cleanup.sh`** — reads a TSV of artifacts (`name`, `size_bytes`, `created_epoch`, `workflow_run_id`) and applies three retention policies, then emits a deletion plan + summary:
  - `--max-age-days N` — delete artifacts older than N days (vs. a pinned `--now` for determinism)
  - `--keep-latest N` — keep the N newest artifacts per workflow run id
  - `--max-total-size B` — delete oldest survivors until the retained total fits
  - `--dry-run` mode; graceful errors for missing/malformed input. Passes `bash -n` and `shellcheck`.
- **`tests/cleanup.bats`** — 9 unit tests written test-first (one policy at a time, red→green).
- **`tests/workflow.bats`** — 8 structure tests (triggers, jobs, `needs`, permissions, `checkout@v4`, referenced files exist, actionlint exit 0).
- **`.github/workflows/artifact-cleanup-script.yml`** — `push`/`pull_request`/`schedule`/`workflow_dispatch` triggers, least-privilege `contents: read`, three dependent jobs (`validate` → `test` → `plan`), runs the script against committed fixtures. Passes `actionlint` cleanly.
- **`run-act-tests.sh`** + **`tests/act.bats`** — act harness: per case, builds a throwaway git repo with project files + that case's fixture/policy, runs `act push --rm`, appends delimited output to `act-result.txt`, asserts exit 0, asserts every job shows "Job succeeded", and asserts **exact** values (e.g. case 1 reclaims exactly `300 bytes`, case 3 yields `Retained: 1 / Deleted: 2 / Space reclaimed: 400 bytes`).
- **`act-result.txt`** — all 3 cases exit 0, **9 "Job succeeded", 0 failures**.

The final run is fully green.
