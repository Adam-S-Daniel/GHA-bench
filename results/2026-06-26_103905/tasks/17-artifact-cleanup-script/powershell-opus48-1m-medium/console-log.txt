## Solution (PowerShell, TDD)

**Core engine — `ArtifactCleanup.psm1`**
- `New-ArtifactObject` — normalises/validates raw metadata (parses ISO-8601 dates, rejects negative sizes).
- `Invoke-ArtifactRetention` — pure function that applies three independent, optional retention policies and returns a deletion *plan* (it never deletes anything itself, making dry-run trivial):
  1. **keep-latest-N per workflow** — groups by artifact name, keeps the N newest.
  2. **max age** — deletes anything older than N days (uses an injectable `ReferenceDate` for deterministic tests).
  3. **max total size** — deletes oldest survivors until the retained set fits under the cap.
  - Returns `Deleted`, `Retained`, and a `Summary` (`DeletedCount`, `RetainedCount`, `SpaceReclaimed`, `DryRun`).

**Entry script — `Invoke-Cleanup.ps1`** — loads JSON fixtures, runs the engine, prints a human-readable plan plus a machine-parseable `KEY=VALUE` summary block. Graceful errors with exit codes.
