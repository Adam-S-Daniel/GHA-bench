## Solution overview

A PowerShell artifact-cleanup tool built **test-first** (red/green TDD with Pester) and verified **end-to-end through `act`**.

### Core logic — `ArtifactCleanup.psm1`
Pure, unit-testable functions. `Get-ArtifactCleanupPlan` applies three retention policies and returns a plan (retained/deleted lists + summary):

1. **Max age** — deletes artifacts strictly older than *N* days (exact boundary kept).
2. **Keep latest N per workflow** — groups by artifact **Name** (each name = one workflow's artifact stream, run id distinguishes runs), keeps the *N* newest, ties broken by higher/newer run id.
3. **Max total size** — applied last over survivors; evicts oldest-first until the retained total fits.

An artifact is deleted if **any** policy flags it, and **every** applicable reason is recorded. The reference "now" is injectable for deterministic tests. `Invoke-ArtifactCleanup` drives loading → planning → (optional) deletion, with **dry-run** that never invokes the delete action.

### TDD discipline
Each behavior went red → green → next: no-policy, max-age, keep-N (+ tie-break), max-size (+ no-op), combined/multi-reason, empty-input edge, `Format-FileSize`, summary enrichment, report rendering, fixture loading, and error handling (missing file / bad JSON / missing field).
