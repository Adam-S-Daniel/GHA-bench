## Summary

I built **Task 17: Artifact Cleanup Script** in Python (pure standard library, no `pip install` needed), using red/green TDD throughout.

### The engine — `artifact_cleanup.py`
A deletion planner with three independently-toggleable retention policies, applied deterministically:
1. **`max_age_days`** — delete artifacts older than the cutoff.
2. **`keep_latest_n`** — per workflow group, keep the N newest, delete the surplus.
3. **`max_total_size_bytes`** — applied last (on survivors), evicts oldest-first until under budget.

Deletion reasons accumulate, all ordering has stable tie-breaks (time → run id → name), and it produces a summary (`space_reclaimed`, retained vs deleted counts/bytes) in **text** or **JSON**, with **dry-run** mode. Errors raise `CleanupError` → meaningful stderr message + exit code 2.
