- **Matrix-in-one-run** reconciles "every test case through act" with the 3-`act`-run budget — a single `act push` covers all 5 cases with per-case isolation. I used **2 of 3** runs (1 reserve).
- **`--pull=false`** because the act image is local-only (not in any registry); a default pull would have failed.
- Handled the **PyYAML `on:` → `True`** YAML 1.1 gotcha in structure tests.
- Per-case parsing filters by job tag, robust to interleaved parallel matrix output.
