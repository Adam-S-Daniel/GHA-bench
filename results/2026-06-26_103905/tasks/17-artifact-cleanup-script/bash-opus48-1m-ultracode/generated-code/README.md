# Artifact Cleanup Script (Task 17)

A Bash retention-policy engine for CI artifacts. Given mock artifact metadata
(`name`, `size`, `creation date`, `workflow run id`), it applies up to three
retention policies, decides which artifacts to delete, and prints a deletion
plan plus a summary (space reclaimed, retained vs deleted). It defaults to a
safe **dry run**.

## Files

| Path | Purpose |
| --- | --- |
| `artifact-cleanup.sh` | The retention-policy engine. |
| `fixtures/case*.txt` | Self-describing mock-data test cases (each carries its own `# policy:` header). |
| `test/artifact-cleanup.bats` | bats-core suite: workflow-structure checks + the act-driven pipeline tests. |
| `.github/workflows/artifact-cleanup-script.yml` | CI pipeline that runs the engine over every fixture. |
| `act-result.txt` | Captured output of the single `act push` run (generated by the test suite). |

## Retention policies

Any combination may be active; an unset policy is disabled. They are applied in
a deterministic order, because the size cap operates on whatever still survives:

1. **`--max-age-days N`** — delete artifacts strictly older than N days.
2. **`--keep-latest N`** — per **workflow run id**, keep only the N newest
   artifacts (by creation date); delete the rest. (`run_id` is the grouping
   key.)
3. **`--max-total-size BYTES`** — cap the total *retained* size. If survivors of
   the first two policies still exceed the cap, delete **oldest-first** until the
   total fits.

When more than one policy would delete an artifact, the **first** policy to act
owns the `reason` shown in the plan.

## Usage

```bash
# Dry run (default) with policies supplied on the command line:
./artifact-cleanup.sh --input fixtures/case1-age.txt \
    --max-age-days 30 --now 2026-06-28T00:00:00Z

# Policies can instead live in the fixture's "# policy:" header, so a file is
# self-describing (CLI flags override file policy):
./artifact-cleanup.sh --input fixtures/case4-combined.txt --now 2026-06-28T00:00:00Z

# Read from stdin and actually perform (mock) deletions:
cat artifacts.txt | ./artifact-cleanup.sh --input - --execute
```

`--now` pins the reference time (ISO8601 or epoch seconds) so age-based results
are reproducible; it defaults to the current UTC time.

### Input format

Pipe-delimited (default; configurable with `--delimiter`), one artifact per
line. Blank lines and `#` comments are ignored; a `# policy: key=value ...`
comment sets policy defaults.

```
# policy: max-age-days=30 keep-latest=2 max-total-size=8000000
name|size_bytes|created_iso8601|run_id
old-build|10000000|2026-05-01T00:00:00Z|1001
```

## Testing

```bash
bats test/artifact-cleanup.bats
```

The suite was built red/green with TDD. Per the task, **all functional test
cases run through the GitHub Actions pipeline via `act`**: `setup_file` runs
`act push --rm` exactly once (the workflow processes every fixture in that single
invocation, keeping within the act-run budget), captures everything to
`act-result.txt`, and each test asserts on exact known-good values from that
capture. The suite also validates the workflow structure and that `actionlint`
passes.
