## Solution Overview

**`cleanup.ts`** — the artifact retention planner + CLI. A pure `planCleanup(artifacts, policy, options)` function applies three retention policies and returns a deletion plan with a summary:
- **max age** — delete artifacts older than `maxAgeDays`
- **keep-latest-N per workflow** — protect the N newest artifacts per workflow from deletion *and* prune everything beyond N
- **max total size** — evict oldest artifacts until retained size is within budget
- Protected (keep-latest-N) artifacts are never deleted, even to satisfy the size cap. Supports **dry-run** mode and an injectable clock (`now`) for deterministic results. `renderReport()` emits stable `KEY=value` lines; `loadConfig()`/`main()` provide `bun run cleanup.ts <config.json>`.

**`cleanup.test.ts`** — built red→green via TDD (15 unit tests: no-policy, max-age, keep-latest-N, max-size, combined, dry-run, error handling, and report rendering).

**`workflow.test.ts`** — workflow structure tests (triggers, permissions, job dependency, action refs, script-path existence, `actionlint` exit 0) **plus** the act execution harness that, per test case, builds an isolated temp git repo, writes the fixture to `fixtures/active.json`, runs `act push --rm --pull=false`, appends all output to `act-result.txt`, and asserts exit 0, both jobs "Job succeeded", and **exact** plan values.

**`.github/workflows/artifact-cleanup-script.yml`** — triggers on push/pull_request/schedule/workflow_dispatch, least-privilege `contents: read`, a `test` job (`bun test cleanup.test.ts`) and a dependent `cleanup-plan` job that runs the script and publishes to the job summary.
