## Summary

I built an **environment matrix generator** in TypeScript/Bun using strict red/green TDD, with a real GitHub Actions pipeline validated through `act`.

### What it does
Given a config of OS options, language versions, and feature flags, it generates a GitHub Actions `strategy.matrix` (JSON), faithfully implementing GitHub's documented `include`/`exclude` semantics, plus `max-parallel`, `fail-fast`, and a max-size safety valve.

### TDD process (red→green for each piece)
`cartesianProduct` → `applyExclude` → `applyInclude` (pinned to GitHub's *own* canonical documentation example) → `generateMatrix` (exclude-then-include ordering + max-size validation) → `parseConfig` (graceful, field-named errors) → CLI core → executable wrapper.

### Files
- `src/types.ts`, `src/matrix.ts` (pure logic), `src/cli.ts` (text⇄strategy), `src/generate.ts` (executable: argv/file/stdin/stdout/exit codes)
- `tests/` — 5 suites; `fixtures/` — 3 configs doubling as test fixtures
- `.github/workflows/environment-matrix-generator.yml` — 3-job pipeline (`generate-matrix` → dynamic `fromJson` `build` matrix → `summary` fan-in)
- `README.md`, `act-result.txt` (required artifact)

### Results
- **`bun test`**: 56 pass, 0 fail (19 act tests opt-in via `RUN_ACT=1` so the default suite stays fast & Docker-free)
- **`RUN_ACT=1 bun test tests/act.test.ts`**: 18/18 pass — every fixture runs through the real workflow via `act push`, exit 0, with assertions on **exact** values (counts 4/4/2, max-parallel 2/2/1, fail-fast true/**false**/true, full include-list JSON) and every job "Job succeeded"
- **`actionlint`**: clean (exit 0), also asserted by a structure test

### One bug found & fixed via diagnosis (not blind re-runs)
The first `act` run surfaced a single assertion failure: `jq '."fail-fast" // "none"'` collapses boolean **`false`** to the default (jq's `//` fires on `null` *or* `false`), so `fail-fast: false` printed `none`. I fixed it with explicit `has(...)` checks, verified the fix against all three fixtures locally, then did one confirming `act` run — all green.
