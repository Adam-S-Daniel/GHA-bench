### Key design points
- Config mirrors a GitHub `strategy` block; output is a flattened `{"matrix":{"include":[...]}}` directly consumable via `fromJSON()`.

- Every failure raises `MatrixError` with a meaningful message; the CLI maps that to a non-zero exit + `Error:` on stderr.
