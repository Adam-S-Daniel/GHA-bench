## Solution overview

**`matrix_generator.py`** — the generator. Takes a declarative config (`axes`, `include`, `exclude`, `max_parallel`, `fail_fast`, `max_size`) and emits a GitHub-Actions `strategy` object as JSON. It faithfully mirrors GitHub's own semantics:
1. Cartesian product of axes (declaration order, last axis fastest)
2. `exclude` rules applied first (subset-matching drops every matching combo)
3. `include` rules applied with GitHub's documented merge-or-append algorithm (verified against GitHub's own example in a test)
4. `max_size` validation with an actionable error message
5. Output as `matrix.include` — the canonical shape for a *dynamically generated* matrix, directly consumable via `fromJSON`

CLI errors go to stderr with non-zero exit and meaningful messages.

## GitHub Actions pipeline
**`.github/workflows/environment-matrix-generator.yml`** — triggers on push/pull_request/workflow_dispatch/schedule, least-privilege `contents: read`, two jobs:
