### Key design decisions
- **Output is an "include-only" matrix** (`strategy.matrix.include`) — the fully-resolved combinations GitHub runs verbatim, so the result is unambiguous and directly usable.
- **Size validation is non-fatal by default** (reported via `within-limit`), with `--strict` for hard failure. This lets the over-limit fixture exercise validation end-to-end *while every act job still succeeds*, as required.
- **Per-case fixture selection** via `CONFIG_FILE` (set through `act --env`) demonstrates env-var usage without copying files; the `report` job depends on `generate-matrix` and consumes its output via `fromJSON`/`jq` — a real dynamic-matrix pattern.
- Assertions check **exact values** — size, within-limit, fail-fast, max-parallel, include-count, and the complete expanded `include` array (e.g. exclude-include yields exactly `10` combinations with the `macos` `experimental` entry appended).
