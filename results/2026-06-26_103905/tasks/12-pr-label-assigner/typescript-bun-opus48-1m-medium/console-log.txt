## What was built

A **PR label assigner** in TypeScript/Bun, developed strictly red/green TDD (each unit driven by a failing test first), with a real CI pipeline validated through `act`.

### Core functionality
- **Glob matching** (`src/glob.ts`): compiles globs to anchored RegExp supporting `*` (within segment), `?`, `**` (cross-segment, incl. matching the dir itself), and basename matching for slash-less patterns like `*.test.*`. Regex metacharacters in literals are escaped.
- **Label assignment** (`src/label-assigner.ts`): a file can receive **multiple labels** from multiple matching rules; the final set is **deduplicated and ordered by descending priority**, with declaration order breaking ties.
- **Config/input parsing** (`src/config.ts`): validates the rules JSON and changed-file list with **meaningful error messages** (invalid JSON, missing `rules`, missing `pattern`/`label`, etc.).
- **CLI** (`src/cli.ts`): explicit arg parsing, graceful errors with exit codes (0/1/2), emits stable `LABELS=`/`LABEL_COUNT=`/`UNMATCHED=` markers, and writes to `$GITHUB_OUTPUT` in CI.
