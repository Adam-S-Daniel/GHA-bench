**Core logic** (`PRLabelAssigner.psm1`) — developed test-first across genuine RED→GREEN cycles:
- `ConvertTo-LabelRegex` — glob→regex (`**` crosses `/`, `*` within a segment, `?` single char, `.` literal)
- `Test-PathPattern` — slash-bearing patterns match the full path; slashless patterns (e.g. `*.test.*`) match the basename anywhere in the tree
- `Get-PRLabels` — accumulates multiple labels per file, unions/dedupes across files, orders by descending **priority** then name, and supports `-FirstMatchWins` for conflict resolution
- `Import-LabelRules` / `ConvertTo-NormalisedRule` — JSON config loading with graceful, meaningful errors (missing file, bad JSON, malformed rules)

**Entry point** (`Invoke-LabelAssigner.ps1`) — resolves inputs from params → env vars → defaults, prints a delimited label block, and writes `$GITHUB_OUTPUT`.
