### What was built

**`pr-label-assigner.sh`** — maps changed file paths to labels via configurable glob rules:
- **Glob semantics** via glob→regex conversion: `*` stays within a path segment, `**` crosses `/`, `?` is one non-`/` char, and slash-free patterns match the basename (so `*.test.*` matches `src/components/Button.test.tsx`).
- **Multiple labels per file** (one rule can list several; multiple rules union and de-dupe).
- **Priority ordering / conflict resolution** — output sorted by priority desc, ties alphabetical; duplicate labels keep their highest priority.
- **Exclusion rules** (`!pattern`) that remove labels per-file (`*` suppresses all).
- Reads files from `--files`, positional args, or stdin; `lines`/`csv` output; meaningful errors with exit codes `2` (usage/IO) and `3` (malformed config).
