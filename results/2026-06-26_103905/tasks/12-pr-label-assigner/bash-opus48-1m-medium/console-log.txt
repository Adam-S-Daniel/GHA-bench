## What I built

A PR label assigner in **Bash**, developed TDD-style and validated entirely through a GitHub Actions pipeline run by `act`.

### Files

| File | Purpose |
|------|---------|
| `label-assigner.sh` | Core script. Reads a changed-file list + rule config, emits the final label set. |
| `rules.conf` | Configurable `glob\|label\|priority` rules. |
| `fixtures/{mixed,docs-only,none}.txt` | Mock PR file lists (test fixtures). |
| `.github/workflows/pr-label-assigner.yml` | CI pipeline: `lint` job → `assign` job (fixture matrix). |
| `test/workflow.bats` | End-to-end tests — every assertion runs through `act`. |
| `test/structure.bats` | Static workflow-structure + lint assertions. |
| `act-result.txt` | Required artifact: full captured `act` output. |

### How the requirements are met

- **Glob patterns** via bash `[[ $path == $pattern ]]` (where `*` spans `/`, so `docs/**`, `src/api/**`, `*.test.*` all work intuitively).
- **Multiple labels per file** — a file matches every applicable rule.
- **Priority ordering / conflict resolution** — each rule carries an integer priority; the same label from several rules keeps the lowest (strongest) number; output is sorted by priority then name (`tests,documentation,api,backend`).
- **Errors handled gracefully** — missing args/files, malformed/non-integer rule lines (warn + skip), empty rule set.
- **Quality gates**: `shellcheck` clean, `bash -n` passes, `#!/usr/bin/env bash` shebang.

### Testing through the pipeline
- `actionlint` passes (exit 0) — validated **before** running `act`.
- All testing flows through the workflow via `act push --rm`. The workflow uses a **fixture matrix**, so one `act` run exercises all three cases — I used **1 of the 3** allowed `act` runs.
- The workflow self-asserts exact label sets and exits non-zero on mismatch; the bats harness additionally asserts **act exit 0**, **exact expected values** (e.g. `LABELS: tests,documentation,api,backend`), and **4× "Job succeeded"** (lint + 3 matrix jobs).

**Final results:** structure.bats 11/11, workflow.bats 7/7, all lint gates clean.
