### What it does
Reads secrets config (`name`, `lastRotated`, `rotationPolicyDays`, `requiredBy`), computes `expiryDate = lastRotated + policy` and `daysUntilExpiry` in **UTC**, classifies into **expired / warning / ok** against a configurable warning window, and renders **markdown** (grouped tables), **json**, or **github** (`$GITHUB_OUTPUT` counters). Strict input validation with precise error messages; CI-friendly exit codes (`0` ok / `1` `--fail-on` breach / `2` error).

### TDD cycles (test-first each time)
1. Date math + per-secret evaluation → `src/validator.ts`
2. Config parsing/validation + report building → `src/config.ts`
3. Formatters (json/markdown/github) → `src/formatters.ts`
4. CLI orchestration with injected I/O → `src/cli.ts` + `validate.ts`

### Workflow (`.github/workflows/secret-rotation-validator.yml`)
Triggers on push/PR/daily-schedule/manual-dispatch; least-privilege `contents: read`; deterministic `ROTATION_NOW`; two jobs — **`validate`** (checkout → setup-bun → run → job summary + outputs) and **`report`** (`needs: validate`, consumes outputs, emits verdict + annotations).
