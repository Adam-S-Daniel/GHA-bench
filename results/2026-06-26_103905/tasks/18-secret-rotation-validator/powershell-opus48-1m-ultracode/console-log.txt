## What was built

A **Secret Rotation Validator** in PowerShell, developed with genuine red/green TDD and wired into a GitHub Actions pipeline exercised through `act`.

### TDD (6 red→green cycles, 42 Pester tests)
Each function was written test-first, run to confirm RED, then implemented to GREEN:
1. `Get-SecretRotationStatus` — classifies a secret expired/warning/ok (boundary: due-today = warning)
2. `Import-SecretConfig` — JSON parse + validation with named, actionable errors (missing file, bad JSON, missing/invalid fields)
3. `Get-RotationReport` — urgency grouping + summary counts, most-overdue-first
4. `Format-RotationReport` — Markdown table grouped by urgency **and** clean JSON
5. `Invoke-SecretRotationValidator` — orchestration, param precedence (flag → config → default), exit-code guardrail, file output
6. `Get-RotationSummaryMarkers` — StrictMode-safe CI markers (added after a real bug surfaced)

The script is dual-purpose: dot-sourceable for tests, runnable as a CLI (with env-var fallbacks and exit codes 0/1/2).

### Pipeline (`.github/workflows/secret-rotation-validator.yml`)
Triggers on push / PR / weekly cron / manual dispatch; least-privilege `contents: read`; workflow env + dispatch inputs; two dependent jobs (`rotation-report` `needs: unit-tests`); all PowerShell via `shell: pwsh`.
