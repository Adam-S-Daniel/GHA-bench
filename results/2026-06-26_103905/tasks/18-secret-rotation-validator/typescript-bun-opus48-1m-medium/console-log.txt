## Summary

I built a **Secret Rotation Validator** in TypeScript/Bun using red/green TDD, plus a GitHub Actions pipeline tested end-to-end through `act`.

### The tool
- `src/validator.ts` — domain model + pure `classifySecret` urgency logic (`expired` / `warning` / `ok`), with an injectable `now` for determinism and strict date parsing.
- `src/config.ts` — JSON config parsing/validation with descriptive errors (bad JSON, wrong shape, missing fields, non-positive policy, non-string `requiredBy`).
- `src/report.ts` — groups secrets by urgency, sorts soonest-due-first, summarizes counts.
- `src/format.ts` — renders **markdown table** and **JSON** (notifications grouped by urgency).
- `src/cli.ts` — `runCli` orchestration (pure w.r.t. I/O via injected clock + file reader) and a thin `main()`. Flags: `--config`, `--format`, `--warning-window`, `--now`, `--help`. Exit codes: 0 = all OK, 1 = expired present, 2 = usage/config/I/O error.

### TDD
Each piece was driven by a failing test first (`tests/classify`, `report`, `format`, `config`, `cli`). **36 tests pass** with `bun test`, including workflow-structure tests that parse the YAML, verify triggers/jobs/`needs`/referenced paths, and run actionlint (skipped gracefully where the binary is absent).

### CI/CD + act
- `.github/workflows/secret-rotation-validator.yml` — triggers on push/PR/schedule/workflow_dispatch; read-only permissions; pinned `REPORT_NOW` for deterministic output; a `test` job and a `validate` job (`needs: test`) that checkout → setup-bun → install → run the CLI in markdown and JSON. **Passes actionlint (exit 0).**
- `harness/act-harness.ts` — for each of 3 fixtures (mixed / all-ok / all-expired) it builds an isolated temp git repo, runs `act push --rm`, appends delimited output to **`act-result.txt`**, and asserts exact values.
