## Solution

**`secret-rotation-validator.sh`** — a Bash tool that reads a JSON config of secrets (name, last-rotated date, rotation policy in days, required-by services), classifies each as **expired** / **warning** / **ok** against a configurable warning window, and emits a grouped report as a Markdown table or JSON. Date math runs in UTC to avoid DST off-by-one errors; the `--now` flag (and `$ROTATION_NOW`) makes results deterministic for CI/tests. Passes `shellcheck` and `bash -n` cleanly.

## TDD methodology
Started with a single failing test (RED, exit 127), wrote the minimal script to pass (GREEN), then expanded to **26 unit tests** in `test/rotation.bats` covering classification boundaries, summary counts, both output formats, strict mode, and 10 error paths — all with pinned dates for determinism.

## GitHub Actions
`.github/workflows/secret-rotation-validator.yml`:
- Triggers: `push`, `pull_request`, `schedule` (daily cron), `workflow_dispatch` (with defaulted inputs)
- `permissions: contents: read` (least privilege)
- Two jobs with a dependency: `validate` generates the report and exports per-urgency counts as job outputs; `summarize` (`needs: validate`) consumes them and annotates the run
- Passes `actionlint` with exit 0

## act integration (all testing through the pipeline)
