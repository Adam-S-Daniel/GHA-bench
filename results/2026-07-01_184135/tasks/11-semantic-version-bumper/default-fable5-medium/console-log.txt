## What was built

A zero-dependency Node.js semantic version bumper (`src/bumper.js`) that reads a version from a plain `VERSION` file or `package.json`, classifies conventional commits (breaking → major, `feat` → minor, `fix` → patch, highest wins), updates the version file in place, prepends a grouped changelog entry to `CHANGELOG.md`, and prints `NEW_VERSION=x.y.z`. Errors (missing files, malformed versions, invalid JSON) all fail with specific messages and exit code 1.
