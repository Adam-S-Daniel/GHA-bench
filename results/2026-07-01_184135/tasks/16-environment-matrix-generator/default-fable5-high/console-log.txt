## What was built

A Python (stdlib-only) **environment matrix generator** — `matrix_generator.py` — that turns a JSON config of OS options, language versions, and feature flags into a GitHub Actions `strategy.matrix` document. It mirrors GitHub's real semantics: cartesian product of axes, `exclude` rules with partial matching (applied first), `include` rules that expand matching combinations without overwriting original axis values (non-matching entries become standalone combinations), `fail-fast` (default true) and `max-parallel` passthrough, and a `max-size` guard defaulting to GitHub's own 256-job limit. Errors (missing/malformed config, empty axes, non-scalar values, oversized matrix, empty matrix after excludes) all fail with messages naming the offending field.
