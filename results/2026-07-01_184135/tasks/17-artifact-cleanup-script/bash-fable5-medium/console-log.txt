## What was built

**`artifact-cleanup.sh`** — the retention engine. It reads a TSV of mock artifact metadata (name, size, ISO 8601 creation date, workflow run ID) and applies three optional policies in order: `--max-age-days` deletes anything older than the cutoff, `--keep-latest N` keeps only the newest N artifacts per workflow run, and `--max-total-size` drops the oldest retained artifacts until the total fits the byte budget. It emits a tab-separated deletion plan (each `DELETE` line carries the policy that triggered it) plus a summary with retained/deleted counts and total space reclaimed. `--dry-run` prints the plan without deleting; real mode performs a mock deletion per planned artifact. `--now` injects the reference time so tests are deterministic. Errors (missing input, malformed lines, bad dates, non-numeric policy values) exit with meaningful messages on distinct exit codes.

**TDD process**: I wrote all 12 behavioral bats tests first and ran them to confirm 12 failures (red), then implemented the script to make them pass (green), with a small shellcheck-driven refactor. Fixtures live in `tests/fixtures/`.

**Test suites** (18 bats tests total, all passing):
- `tests/artifact_cleanup.bats` — 12 tests covering each policy, combined-policy ordering, summary math, dry-run vs. real mode, and error handling.
- `tests/workflow.bats` — 6 workflow structure tests: YAML validity, expected triggers (`push`, `pull_request`, `schedule`, `workflow_dispatch`), job dependency (`cleanup-plan` needs `test`), permissions + `actions/checkout@v4`, referenced script paths exist and are executable, and actionlint exits 0.

**Workflow** at `.github/workflows/artifact-cleanup-script.yml` — two jobs: `test` installs bats and runs both suites; `cleanup-plan` (dependent) runs `ci/run-cleanup.sh`, which reads policy config from `ci-fixtures/policy.env` and generates the plan. It passes `actionlint` cleanly, and all scripts pass `shellcheck` and `bash -n`.

**Act harness** (`run-act-tests.sh`) ran two end-to-end cases through `act push --rm`, each executing the full bats suite plus a distinct fixture scenario in the container.
