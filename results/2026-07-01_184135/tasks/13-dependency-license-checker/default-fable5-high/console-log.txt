## What was built

A zero-dependency Node.js license compliance checker, developed strictly red/green TDD — six cycles, each with a failing test confirmed before implementation:

1. `parsePackageJson` — extracts name/version from `dependencies` + `devDependencies`, strips semver range prefixes, meaningful error on bad JSON
2. `parseRequirementsTxt` — pinned/ranged/bare requirements, comment handling, per-line error messages
3. `checkLicenses` — classifies against allow/deny config via an **injected mock license table** (deny-list wins over allow, case-insensitive, unresolvable → `unknown`)
4. `formatReport` — one `name@version | license | STATUS` line per dependency plus an exact-count summary
5. `detectManifest` — auto-detects the manifest type in a directory, clear errors for missing dir/manifest
6. `runChecker` + CLI — end-to-end with on-disk config and mock DB (`--strict` flag makes denied licenses fail the build; CI runs report-only)

**19 unit tests, all passing** (`node --test`).

## CI pipeline

`.github/workflows/dependency-license-checker.yml` — triggers on push, pull_request, workflow_dispatch, and a weekly schedule; `permissions: contents: read`; a `test` job (unit suite) gates a `license-check` job (`needs: test`) that generates the report from env-configured paths and publishes it to the job summary. **actionlint passes cleanly** (verified before any act run).
