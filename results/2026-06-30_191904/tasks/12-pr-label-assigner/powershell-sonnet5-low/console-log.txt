- **`src/LabelAssigner.ps1`** — `Get-PrLabels` matches changed files against glob-pattern rules (`**`, `*`, `?`, gitignore-style basename patterns like `*.test.*`), supports multiple labels per file, de-dupes, and orders by descending priority when rules conflict.
- **`src/Invoke-LabelAssigner.ps1`** — CLI entry point reading a JSON fixture (changed files + rules) for use in CI.
- **`tests/LabelAssigner.Tests.ps1`** — 11 tests covering basic matching, multi-label, dedup, priority ordering, and error handling; each written red-first.
- **`tests/Workflow.Tests.ps1`** — 10 tests validating workflow YAML structure and actionlint pass/fail.
- **`.github/workflows/pr-label-assigner.yml`** — triggers on push/pull_request/workflow_dispatch/schedule, `unit-tests` job runs Pester, `assign-labels` job (depends on it) runs the script against two fixtures.
- **`fixtures/*.json`** — mocked PR file lists exercising docs/api/tests labeling and a priority conflict.
- **`act-result.txt`** — captured output from a real `act push` run (both jobs succeeded), with exact assertions verified: Pester "Tests Passed: 11, Failed: 0", `LABELS: tests,api,documentation` and `LABELS: high-priority,low-priority`.
