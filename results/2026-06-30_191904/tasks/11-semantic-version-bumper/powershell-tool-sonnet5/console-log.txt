**Bug caught by going through the real pipeline**: `Write-Error` in the catch block was silently becoming a terminating error under GitHub Actions' `pwsh` shell (which prepends `$ErrorActionPreference = 'Stop'`), skipping `exit 1`. This only surfaced when running through `act` — exactly what the "test through the pipeline" requirement was designed to catch. Fixed with explicit `-ErrorAction Continue`, then added a regression test that reproduces the same preference locally.
