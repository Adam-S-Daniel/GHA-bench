PROJECT TITLE
═══════════════════════════════════════════════════════════════════════════════
Semantic Version Bumper with GitHub Actions Integration

DESCRIPTION
═══════════════════════════════════════════════════════════════════════════════
A production-ready bash script that automatically determines and applies
semantic versioning based on conventional commit messages. Built using
Test-Driven Development (TDD) methodology with comprehensive test coverage
and GitHub Actions integration.

KEY TECHNOLOGIES
═══════════════════════════════════════════════════════════════════════════════
- Bash shell scripting
- Git commit analysis
- JSON parsing (package.json)
- Text file processing (VERSION)
- GitHub Actions workflow
- Docker/act for CI/CD testing
- Test-Driven Development (TDD)

HOW TO USE
═══════════════════════════════════════════════════════════════════════════════

DIRECT SCRIPT USAGE:
  chmod +x version-bumper.sh
  ./version-bumper.sh --parse-version package.json
  ./version-bumper.sh --next-version package.json
  ./version-bumper.sh --update-version package.json 1.1.0
  ./version-bumper.sh --changelog-from-commits

GITHUB ACTIONS (AUTOMATIC):
  1. Push to main/master
  2. Workflow runs automatically
  3. Check "Detect Version and Generate Changelog" job
  4. View outputs in workflow run details

GITHUB ACTIONS (MANUAL):
  gh workflow run semantic-version-bumper.yml \
    -f version_file=package.json \
    -f dry_run=true

RUN TESTS:
  bash RUN_ALL_TESTS.sh                  # All tests
  bash test-version-bumper.sh            # Unit tests only
  bash test-workflow-structure.sh        # Structure validation
  bash test-with-act.sh                  # Integration tests
