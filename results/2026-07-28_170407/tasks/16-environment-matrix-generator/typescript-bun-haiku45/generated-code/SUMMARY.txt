PROJECT OVERVIEW
================================================================================

A production-ready TypeScript/Bun tool that generates GitHub Actions build
matrices from configuration. Produces valid strategy.matrix JSON with support
for include/exclude rules, parallel limits, and matrix size validation.

================================================================================
USAGE EXAMPLE
================================================================================

Config file (config.json):
{
  "os": ["ubuntu-latest", "macos-latest"],
  "nodeVersion": ["18", "20"],
  "excludeRules": [{"os": "macos-latest", "nodeVersion": "18"}],
  "maxParallel": 4,
  "failFast": false
}

Command:
$ bun run cli.ts config.json

Output (valid GitHub Actions strategy.matrix):
{
  "matrix": {
    "include": [
      {"os": "ubuntu-latest", "nodeVersion": "18"},
      {"os": "ubuntu-latest", "nodeVersion": "20"},
      {"os": "macos-latest", "nodeVersion": "18"},
      {"os": "macos-latest", "nodeVersion": "20"}
    ],
    "exclude": [
      {"os": "macos-latest", "nodeVersion": "18"}
    ]
  },
  "maxParallel": 4,
  "failFast": false
}
