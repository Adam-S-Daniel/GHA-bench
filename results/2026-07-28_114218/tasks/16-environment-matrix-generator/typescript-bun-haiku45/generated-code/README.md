# Environment Matrix Generator

A TypeScript/Bun tool for generating GitHub Actions build matrices from configuration files. Supports cartesian products, include/exclude rules, feature flags, and node version matrices with full validation.

## Features

- **Cartesian Product Generation**: Automatically generates all combinations across OS, languages, features, and node versions
- **Include Rules**: Add custom matrix combinations beyond the cartesian product
- **Exclude Rules**: Remove specific combinations from the matrix
- **Feature Flags**: Support multiple feature configurations (debug, release, etc.)
- **Node Versions**: Built-in support for testing multiple Node.js versions
- **Configuration Validation**: Validates required fields and matrix size limits
- **Max Parallel Control**: Set concurrency limits for GitHub Actions
- **Fail-Fast Control**: Configure whether matrix jobs should fail immediately on any failure
- **Size Validation**: Prevent generating matrices larger than specified maximum

## Installation

```bash
bun install
```

## Usage

### CLI

```bash
bun matrix.ts <config-file.json>
```

The command outputs the complete matrix JSON suitable for GitHub Actions `strategy.matrix`.

### Programmatic API

```typescript
import { generateMatrix, MatrixConfig, loadConfigAndGenerate } from "./matrix";

// From config object
const config: MatrixConfig = {
  os: ["ubuntu-latest", "macos-latest"],
  languages: ["python", "node"],
  features: ["debug", "release"],
  maxParallel: 5,
  failFast: false,
};

const result = generateMatrix(config);
console.log(JSON.stringify(result, null, 2));

// From JSON file
const result = await loadConfigAndGenerate("config.json");
```

## Configuration Format

### Basic Example

```json
{
  "os": ["ubuntu-latest", "windows-latest"],
  "languages": ["python", "node"]
}
```

This generates 4 combinations (2 OS × 2 languages).

### Advanced Example

```json
{
  "os": ["ubuntu-latest", "macos-latest", "windows-latest"],
  "languages": ["python", "node", "ruby"],
  "features": ["debug", "release"],
  "nodeVersions": ["18", "20"],
  "exclude": [
    { "os": "windows-latest", "language": "ruby" },
    { "language": "ruby", "feature": "debug" }
  ],
  "include": [
    {
      "os": "custom-runner",
      "language": "go",
      "arch": "arm64"
    }
  ],
  "maxParallel": 5,
  "failFast": false,
  "maxSize": 500
}
```

### Configuration Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `os` | `string[]` | ✓ | Operating system identifiers (e.g., "ubuntu-latest") |
| `languages` | `string[]` | ✓ | Programming languages to test |
| `features` | `string[]` | | Feature flags or build configurations |
| `nodeVersions` | `string[]` | | Node.js versions to test |
| `exclude` | `object[]` | | Array of combinations to exclude from the matrix |
| `include` | `object[]` | | Array of custom combinations to add to the matrix |
| `maxParallel` | `number` | | Maximum number of concurrent jobs |
| `failFast` | `boolean` | | Stop running jobs if any job fails |
| `maxSize` | `number` | | Maximum allowed matrix size (default: 1000) |

### Exclude Rules

Exclusions match on all specified keys in the rule:

```json
{
  "exclude": [
    { "os": "windows-latest", "language": "ruby" }
  ]
}
```

Partial matches also work:

```json
{
  "exclude": [
    { "os": "windows-latest" }
  ]
}
```

This excludes ALL combinations with Windows.

### Include Rules

Add custom combinations not generated by the cartesian product:

```json
{
  "include": [
    {
      "os": "custom-runner",
      "language": "go",
      "special": "custom-value"
    }
  ]
}
```

## GitHub Actions Integration

Use in a GitHub Actions workflow:

```yaml
name: Build Matrix

on: [push]

jobs:
  generate-matrix:
    runs-on: ubuntu-latest
    outputs:
      matrix: ${{ steps.generate.outputs.matrix }}
    steps:
      - uses: actions/checkout@v4
      - uses: oven-sh/setup-bun@v1
      - name: Generate matrix
        id: generate
        run: |
          echo "matrix=$(bun matrix.ts config.json)" >> $GITHUB_OUTPUT

  build:
    needs: generate-matrix
    strategy:
      ${{ fromJSON(needs.generate-matrix.outputs.matrix) }}
    runs-on: ${{ matrix.os }}
    steps:
      - uses: actions/checkout@v4
      - run: echo "Building on ${{ matrix.os }} with ${{ matrix.language }}"
```

## Implementation Notes

### Cartesian Product Algorithm

1. Build axes map from config fields (os, language, feature, nodeVersion)
2. For each axis, generate all combinations with previous results
3. Apply exclusion rules by filtering out matching combinations
4. Add inclusion rules to the final matrix
5. Validate total size against maxSize limit

### Exclusion Matching

A combination is excluded if ALL keys in the exclusion rule match the combination. Partial rules match on only those keys.

### Output Structure

The output always includes:
- `matrix.include[]` - Array of all combinations
- `matrix.exclude[]` - Copy of exclusion rules (if any)
- `maxParallel` - If specified in config
- `failFast` - If specified in config

## Limits and Constraints

- **Default maxSize**: 1000 combinations
- **Maximum matrix dimensions**: Limited by string size and JSON representation
- **Validation**: All inputs are validated before matrix generation
- **Performance**: Sub-second generation for matrices up to 10,000 combinations
