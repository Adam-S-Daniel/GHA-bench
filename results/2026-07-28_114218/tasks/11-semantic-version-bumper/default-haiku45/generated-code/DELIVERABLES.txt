9. USAGE EXAMPLES
================================================================================

Basic Usage:
  python3 bump_version.py --version-file package.json \
                          --changelog-file CHANGELOG.md \
                          --commit-log commits.txt

With Verbose Output:
  python3 bump_version.py --version-file package.json \
                          --commit-log commits.txt \
                          --verbose

Dry Run (no file updates):
  python3 bump_version.py --version-file package.json \
                          --commit-log commits.txt \
                          --no-update

Run Tests:
  python3 -m pytest test_version_bumper.py test_bump_version_cli.py -v

Run via GitHub Actions:
  act push --rm -j test
  act push --rm -j bump-version
  act push --rm -j workflow-validation
