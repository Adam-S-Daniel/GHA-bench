================================================================================
                       ARCHITECTURE NOTES
================================================================================

Core Functions:
  1. parseVersion() → SemanticVersion
     Extracts major.minor.patch from input strings

  2. parseConventionalCommits() → ParsedCommit[]
     Parses conventional commit format with types, scopes, breaking flags

  3. determineNextVersion() → SemanticVersion
     Applies semantic versioning rules based on commit types

  4. updateVersionFile() → void
     Writes new version to package.json or VERSION file

  5. generateChangelog() → string
     Creates markdown changelog grouped by commit type

  6. bumpVersion() → BumpResult
     Orchestrates entire version bump workflow

Design Principles:
  - Single Responsibility: Each function does one thing
  - Pure Functions: No side effects in core logic (except updateVersionFile)
  - Error First: Validate inputs before processing
  - Type Safe: All types explicit, no implicit any
  - Testable: Dependency injection via function parameters
