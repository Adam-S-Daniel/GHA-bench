NEXT STEPS FOR USERS
═══════════════════════════════════════════════════════════════════════════════

1. Copy the script to your project:
   cp src/matrix-generator.sh your-repo/scripts/

2. Create a configuration file:
   cat > matrix-config.json << EOF
   {
     "os": ["ubuntu-latest"],
     "node-version": ["18.x"],
     "features": ["default"]
   }
   EOF

3. Generate matrix:
   ./scripts/matrix-generator.sh matrix-config.json

4. Use in your GitHub Actions workflow:
   strategy: ${{ fromJson(needs.generate.outputs.matrix) }}

5. Run tests locally:
   bats tests/test_*.bats
